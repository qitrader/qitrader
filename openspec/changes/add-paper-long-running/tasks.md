## 7. 线上长跑缺陷修复（2026-09-07）

- [x] 7.1 修复看门狗主动中断被计入连续错误：`interrupt()` 使 `read()` 抛 canceled，累计达到 `kMaxConsecutiveErrors` 后 `read_loop` 提前判死，连接重建后无人读数据，行情永久停滞。改为中断时干净退出且不计入错误（`market/okx/okx_ws.cpp`）。
- [x] 7.2 `write_loop` 同步采用相同判定，避免写循环被主动中断判死。
- [x] 7.3 修复 fd 泄漏：`interrupt()` 原先只关闭通道、不关底层连接，socket 停在 CLOSE-WAIT（线上累积 5 个）。改为派发协程关闭底层连接。
- [x] 7.4 修复优雅退出卡死：`PaperGateway::shutdown()` 未打断 WebSocket，`watch_public` 长期挂在 `read()` 上，SIGTERM 后进程无法退出（只能 kill -9）。改为关闭时主动 `interrupt()`。
- [x] 7.5 修复观测失真：`paper_service.sh status` 的 ERROR 统计用 `grep -c ' ERROR '`，与 glog 行首等级格式不匹配而恒为 0，掩盖故障 5 天。改为按行首等级字符统计。
- [x] 7.6 线上验证：重启后行情按分钟持续增长（382 → 760 → 1140 → 1521 条）、重连保持 0、策略正常成交。
- [x] 7.7 线上验证：优雅退出从"永久挂起"变为 3 秒内结束，绩效报告正常输出。
- [x] 7.8 本地回归：编译通过、`runtime_smoke_test` 7/7 通过。
